# MindFeedNees
MindFeedNees is a serious game that helps to support depression diagnose on people with morbid obesity.
The game was part of the Final Thesis in Computer Engineering, Information and Technology Communication (Bachelor's Degree).

# Gameplay Overview
The player takes choices based on how he feels at the moment. While player is playing match, the game show him a lot of questions which is answered depend of state emotional of player. Select an answer does that the game store states emotionals of player.
It's easy to play.

# Controls
**Left Arrow** - Decision 1
**Right Arrow** - Decision 2

# How to execute
1. Download and install **Unity Hub**  
2. Download the **MindFeedNees** repository  
3. Extract the repository files  
4. In Unity Hub, click **Add Project from Disk** and select the project folder  
5. Unity Hub will prompt you to install **Unity 2022.3.5f1**  
6. Install the required Unity Editor version  
7. Open the **MindFeedNees** project from Unity Hub  
8. Press **Play** in the Unity Editor to run the game
