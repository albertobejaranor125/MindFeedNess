# MindFeedNees

**MindFeedNees** is a serious game developed as part of my Final Graduation Thesis (TFG) for my Bachelor's Degree in Computer Engineering (Information and Communication Technology) at the University of Málaga. The project serves as a technical proof-of-concept aimed at supporting clinicians in the diagnosis of depression in individuals with morbid obesity.

---

## Technical & Architecture Overview

* **Data-Driven Logic:** The core architecture implements a system that dynamically presents psychometric queries to the player based on runtime triggers and state machine variables.
* **State & Emotion Tracking:** User inputs are processed and stored locally, capturing emotional states through structural data logging for potential clinical review.
* **Decoupled UI System:** Developed using modular UI paradigms in Unity, ensuring the presentation layer is entirely separated from the analytical data collection logic.

---

## Gameplay & Controls

The player navigates a series of interactive scenarios, making decisions that directly reflect their current emotional state. 

* ⬅️ **Left Arrow Key:** Decision Option 1
* ➡️ **Right Arrow Key:** Decision Option 2

## How to Execute & Build

1. Download and install **Unity Hub**.
2. Clone or download this repository and extract the files.
3. In Unity Hub, click **Add Project from Disk** and select the root project folder.
4. Unity Hub will automatically prompt you to install the required editor version: **Unity 2022.3.5f1**.
5. Install the editor version, open the project through Unity Hub, and press **Play** in the Unity Editor to run the software.
